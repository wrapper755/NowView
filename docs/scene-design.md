| KPI–KRI–Control | Value Driver 성장·투자 회수 → KPI 신사업 투자회수율 58% (목표 75%) → KRI 신사업 투자회수율 58% (임계 75%) → Control 분기 투자 회수 심의[탐지/정상 수행], 투자 단계별 집행 게이트[예방/미수행] |
| 입력 정보 | Risk Sensing Agent 산출물 (신뢰도 high) · Portfolio Agent 산출물 (신뢰도 low) · Simulation Agent 산출물 (신뢰도 medium) · Agent 보고서 3절 · 대응 대안 3안 (효과·비용·위험·실행 조건) · Agent 미답 질문 2건 |
| 사람의 역할 | 재무팀 — 대안 선택 및 승인. 사유 10자 이상 필수. |
| Agent의 역할 | 분석·대안 제시까지. 선택과 승인에는 관여하지 않는다. |
| BPM의 역할 | waiting 상태로 정지. 승인 이벤트가 있어야 전이한다. |
| 출력 | 미정의 — 경영 판단 기준 작성 필요 |
| 검증 기준 | 사유 10자 이상 입력 시에만 승인 가능 (UI·API 양쪽에서 검증). 승인 시 결정 사유가 실행 과제에 함께 배포된다. |

### 장면 6. 세 안건이 한 Plan에 모인다

> 수익성·납기·배분 세 안건의 승인 과제가 같은 Rolling Plan에 잡힌다. 전사 Gap은 셋이 나눠 메운다.

| 항목 | 내용 |
|---|---|
| 시작 조건 | 투자·운영계획 반영 완료 |
| 관련 프로세스 | Rolling Plan Update / Forecast·Plan 동시 조정 (시스템 자동 수행) |
| KPI–KRI–Control | Value Driver 성장·투자 회수 → KPI 신사업 투자회수율 58% (목표 75%) → KRI 신사업 투자회수율 58% (임계 75%) → Control 분기 투자 회수 심의[탐지/정상 수행], 투자 단계별 집행 게이트[예방/미수행] |
| 입력 정보 | Risk Sensing Agent 산출물 (신뢰도 high) · Portfolio Agent 산출물 (신뢰도 low) · Simulation Agent 산출물 (신뢰도 medium) |
| 사람의 역할 | 결과 확인. |
| Agent의 역할 | - |
